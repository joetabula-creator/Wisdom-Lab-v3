WISDOM LAB VERSION 3.0

Open index.html to test on a computer.
For free publication: create a public GitHub repository, upload index.html, manifest.webmanifest, icon.svg, sw.js, then enable Settings > Pages > Deploy from branch > main / root.

Question bank: 300 questions (100 per age group), also exported in questions.json for editing. The question data is embedded in index.html, so updating questions.json alone does not change the app; regenerate index.html when editing the bank.
Rotation: 10 questions per age group every 48 hours, anchored at 2026-10-26 00:00 UTC. Ten rounds repeat every 20 days.
No server, login, tracking or paid API required.
Important: review all educational content with age-appropriate educators before public use.

NEW: My Life Journey age-appropriate interactive decision simulator. Works locally and on GitHub Pages. No accounts or tracking.
